# 🚀 Daily Routine & Task Manager

> **A simple tool to help you stay consistent, get things done, and build a better daily routine.**

## 📌 About The Project

This project is a **simple but practical daily task and routine manager** designed to help you stay focused and accountable throughout your day.

The idea is simple:

**Write down what you need to do → Complete your tasks → Build consistency.**

But there's one extra thing...

If you don't complete your tasks, **you get punished.** 😈

The goal isn't to make productivity complicated. It's to create a small system that pushes you to actually do the things you said you were going to do.

I built this project because **I personally needed something like this.**
Instead of looking for the perfect productivity app, I decided to build my own.

And that's how this project started.

---

## 🎯 Why I Built It

I wanted a tool that would do more than simply show me a list of tasks.

I wanted something that would make me **responsible for the tasks I create.**

Most To-Do apps let you write tasks and forget about them.

This project takes a different approach:

> **If you don't keep your promises to yourself, there should be a consequence.**

The idea is to gradually create better habits, improve consistency, and make completing daily tasks part of your routine.

---

## ✨ Features

* 📝 Create and manage daily tasks
* ✅ Mark tasks as completed
* 📅 Organize tasks by day
* 🔥 Build consistency in your daily routine
* ⚠️ Get a punishment when tasks are left unfinished
* 🎯 Simple and distraction-free interface
* 💾 Local data storage
* 📊 Track your daily progress

---

## 🧠 The Philosophy

Productivity isn't always about doing more.

Sometimes it's simply about **doing what you said you would do.**

This project is built around that idea.

Set your tasks.
